# Catálogo Universal e Suítes

O **Multitool** consolida **152 ferramentas** rigorosamente curadas para engenharia de software moderna, agentes de inteligência artificial, segurança e produtividade.

---

## 🗂️ 1. Organização por Topos e Categorias

O catálogo é organizado em 5 grandes **Topos**, que agrupam as subsessões temáticas:

| Topo | Categorias Agrupadas | Foco Principal |
| :--- | :--- | :--- |
| **IA** | `Agentes`, `Skills` | Modelos locais, LLMs em terminal, gateways de IA, frameworks e skills de agentes. |
| **Código** | `Editores`, `Versionamento`, `Terminais`, `Fontes` | IDEs, VCS (Git, Jujutsu), emuladores de terminal modernos e tipografia de código. |
| **Sistema** | `Infraestrutura`, `Observabilidade` | Compiladores, runtimes, containers, redes VPN, scraping e monitoramento de telemetria. |
| **Apps** | `Desktop` | Navegadores, reprodutores de mídia, clientes de comunicação e streaming. |
| **Segurança** | `Análise` | Descompiladores binários, análise estática de código (SAST), scanners de vulnerabilidade e CTF. |

---

## 📦 2. Suítes Integradas (@pacotes)

As suítes agrupam ferramentas complementares para fluxos de trabalho específicos:

### 1. `@vibecode` (Vibe Coding & Pair AI)
Conjunto completo para desenvolvimento orientado a IA no terminal:
- `aider`: Programação em par no terminal com git diff automático.
- `repomix`: Empacotador de repositório completo em contexto otimizado para LLMs.
- `astgrep`: Busca estrutural e reescrita de código baseada em AST.
- `ollama`: Servidor local de modelos de IA (Llama, Qwen Coder, DeepSeek).
- `ripgrep`: Mecanismo de busca ultraveloz por texto (`rg`).
- `jq`: Processador JSON de linha de comando.
- `llm`: CLI universal para múltiplos modelos (Simon Willison).
- `goose`: Agente autônomo da Block/AAIF com suporte a MCP.
- `claudecode`: Agente CLI oficial da Anthropic.
- `opencode`: Agente open-source para terminal.
- `ohmypi`: Agente de código com IDE embutida.
- `9router`: Gateway de IA e proxy local para ferramentas de código.
- `omniroute`: Proxy local multiprovedor com roteamento inteligente.
- `hermes`: Agente auto-evolutivo da Nous Research (TUI, gateway, cron e skills).
- `orca`: Orquestrador e ambiente de trabalho para frotas de agentes IA em worktrees paralelos (Grok, Claude Code, Codex, Pi).

### 2. `@mcp` (Model Context Protocol Toolkit)
Ferramentas e pontes do ecossistema MCP:
- `mcpm`: Gerenciador de servidores MCP.
- `mcpinspector`: Inspetor e depurador de servidores MCP.
- `supergateway`: Bridge entre stdio e transporte SSE/WebSockets.
- `codebase_memory`: Grafo de inteligência e memória persistente para LLMs.
- `context7`: Documentação atualizada de bibliotecas para LLMs via MCP.
- `rea`: MCP e toolkit de engenharia reversa para agentes IA.
- `repomix`: Empacotamento de contexto.
- `awsagenttoolkit`: Servidores MCP, skills e plugins oficiais da AWS para agentes de IA.

### 3. `@agentstack` (Agent Engineering & Sandbox)
Harnesses, frameworks e observabilidade para agentes autônomos:
- `langgraph`: CLI do framework de grafos LangGraph.
- `crewai`: Framework de orquestração multi-agentes.
- `ax`: Orquestrador de agentes do Google.
- `bubblewrap`: Sandbox de isolamento e segurança no Linux (`bwrap`).
- `promptfoo`: Framework de avaliação, evals e testes de prompts.
- `phoenix`: Tracing e observabilidade OpenTelemetry para agentes (Arize Phoenix).
- `otelcol`: OpenTelemetry Collector para métricas, traces e logs.
- `podman`: Containers sem daemon.
- `ecc`: Workflows e harness do Everything Claude Code.
- `paperclip`: Governança e orquestração de times de IA.
- `hyperframes`: Framework de vídeo programático para agentes.
- `orca`: Orquestração de frotas de agentes IA em worktrees paralelos.
- `openmausbot`: Alternativa open-source ao Grok Bot / Manus com equipe de agentes IA e VMs.
- `openshell`: Runtime seguro e sandbox com governança para agentes de IA da NVIDIA.

### 4. `@skills` (Coleção Curada de 22 Skills)
Coleção de metodologias e habilidades para agentes de código:
- `superpowers`: Metodologia de desenvolvimento com TDD e planos.
- `impeccable`: Design e frontend limpo sem slop.
- `hallmark`: Design skill anti-AI-slop para Claude Code, OpenCode e Codex (Together AI).
- `awsagenttoolkit`: Servidores MCP, skills e plugins oficiais da AWS para agentes de IA.
- `tasteskill`: Regras de bom gosto estético para agentes.
- `emilkowalski`: Microinterações e animações frontend.
- `archify`: Geração de diagramas de arquitetura de software.
- `opencodereview`: Regras de revisão de código da Alibaba.
- `securityaudit`: Auditoria de segurança de código da Cloudflare.
- `contextmode`: Otimização de context window e compressão de prompt.
- `ponytail`: Regras anti-overengineering e simplificação de código.
- `reverseskill`: Técnicas de engenharia reversa e CTF.
- `pocockskills`: Boas práticas de TypeScript por Matt Pocock.
- `diagramdesign`: Diagramação e comunicação visual técnica.
- `ihaveadhd`: Assistente de foco e redução de sobrecarga cognitiva.
- `addyosmani`: Padrões de arquitetura por Addy Osmani.
- `humanizer`: Eliminação de padrões excessivamente robóticos em textos gerados por IA.
- `openmaic`: Orquestração multi-agente educacional.
- `openseo`: Auditoria de SEO técnico e análise competitiva.
- `linkedin`: Escrita e formatação de artigos técnicos.
- `universalmodder`: Modding e instrumentação de jogos de PC para agentes IA.
- `androidskills`: Skills oficiais do Google para agentes de IA no desenvolvimento Android.

### 5. `@dev` (Ferramentas Essenciais de Desenvolvimento)
- `git`, `gh`, `fzf`, `btop`, `nodejs`, `golang`, `temurin`, `docker`, `vscode`, `neovim`, `waveterm`, `ghostty`, `jj`, `uv`, `rustup`, `bat`.

### 6. `@toolchain` (Compilação C/C++)
